# Roadmap

This repository is and stays **free and open source (MIT)**: the playbook, the scripts and the configs.

## Now
- Playbook v2: SEO + GEO/AEO, measurement, incidents, entity pages, refresh system
- Scripts that are tested, documented (`--help`) and CI-friendly (exit codes)

## Next
- `npx ai-seo-playbook <command>`: a single CLI entry point
- An AI-citation benchmark: a monthly sampled measurement of which domains ChatGPT, Perplexity, Claude and
  Gemini cite for a fixed query set (official APIs only)
- More worked examples from other sites (contributions welcome, with numbers and windows)

## Later
- **Hosted audits** at [valueaddvc.com](https://valueaddvc.com): connect Search Console and get these reports,
  the human-vs-agent split, and a prioritized fix list without running anything.
- The open-source core stays MIT. Hosted features will build on it, not replace it.

Want to follow along or be an early tester? Open a discussion or reach out via [valueaddvc.com](https://valueaddvc.com).
